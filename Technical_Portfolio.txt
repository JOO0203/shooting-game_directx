[포트폴리오 기술서] DirectX 11 기반 고성능 슈팅 게임 엔진 마이그레이션 및 패턴 설계
================================================================================

1. 프로젝트 개요
--------------------------------------------------------------------------------
- 개발 언어 및 환경: C++, DirectX 11 (D3D11), DirectWrite, Direct2D, Windows SDK
- 마이그레이션 동기: 
  * 기존 GDI+ (CPU 기반 렌더링) 환경에서 수천 개의 탄막 처리 시 발생하는 프레임 드랍 한계 직면.
  * GPU 하드웨어 가속을 통한 60FPS 이상의 압도적 성능 및 시각 효과 확보.
- 핵심 목표: 하드웨어 가속 기반의 안정적인 탄막 엔진 구축 및 현대적인 렌더링 파이프라인 확보.

2. 시스템 아키텍처 및 객체 설계 (OOP & DX11 Pipeline)
--------------------------------------------------------------------------------
- DX11 전용 렌더링 엔진 (D3D11Renderer):
  * 상용 엔진 수준의 렌더링 파이프라인 구축 (Vertex/Pixel Shader, Constant Buffer).
  * Orthographic Projection 기반의 2D 전용 좌표계 설계 및 셰이더 기반 이미지 렌더러 구현.
  
- 하이브리드 UI 엔진 제작:
  * Direct2D / DirectWrite를 D3D11과 상호 운용(Interop)하여 고품질 텍스트 및 UI 렌더링 시스템 구축.
  * 기존 GDI+의 폰트 렌더링 병목을 완전히 해결하고 안티앨리어싱이 적용된 미려한 UI 구현.

- 객체 지향 엔티티 구조:
  * Entity (추상 베이스 클래스): DX11 렌더러와 호환되는 위치(Vector2), 피격 범위 관리.
    ├── Player: DirectX 기반 동적 서브 웨폰 및 이펙트 제어.
    ├── Enemy/Boss: GPU 가속 기반의 대규모 탄막 패턴 실행.
    ├── Bullet: 셰이더를 통한 실시간 색상 변조 및 고속 물리 연산.
    └── Explosion: 9프레임 애니메이션 및 투명도 처리가 가미된 고화질 이펙트.

3. 성능 최적화 및 기술 혁신 (GDI+ 사후 분석 및 DX11 해결)
--------------------------------------------------------------------------------
- GDI+의 기술적 한계 및 DX11을 통한 극복:
  * [한계] GDI+는 CPU 점유율이 높고 투명도(Alpha) 처리 시 픽셀 단위 연산으로 프레임 드랍 유발.
  * [해결] DX11 하드웨어 고속 블렌딩(OMSetBlendState)을 통해 수천 개의 투명 탄환도 오버헤드 없이 처리.
  * [한계] 대량 오브젝트 렌더 시 GDI+의 시리얼 드로잉 병목 현상.
  * [해결] GPU 파이프라인 병렬 처리를 통해 렌더링 병목을 0%에 가깝게 최적화.

- 고성능 공간 분할 (Spatial Grid 2.0):
  * Grid Partitioning 알고리즘을 DX11 엔진에 최적화하여 O(N) 수준의 충돌 감지 달성.
  * 연산 부하가 큰 대량 탄막 상황에서도 GPU 가속 렌더링과 시너지를 내어 상시 60FPS+ 유지.

- 지능형 리소스 관리 (ResourceManager DX11):
  * WIC(Windows Imaging Component)를 활용한 고속 이미지 로딩 및 DX11 Texture 리소스 캐싱.
  * 재시작/클리어 시 GPU 메모리 누수를 방지하기 위한 정밀한 리소스 라이프사이클 관리(ComPtr 활용).

- 고정밀 하드웨어 타이밍 및 고정 타임스텝(Fixed TimeStep) 도입: 
  * QueryPerformanceCounter 기반의 정밀 대기 시간을 활용하여 로직 주기를 70Hz(약 14.28ms)로 고정.
  * 하이브리드 어큐뮬레이터(Accumulator) 패턴을 통해 하드웨어 성능과 주사율에 관계없이 항상 동일한 탄막 궤적과 게임 속도를 보장하는 결정론적(Deterministic) 엔진 설계 달성.
  * 타이머 차감 방식(m_fireTimer -= interval)을 적용하여 프레임 간 누적 시간 손실을 제거하고 완벽한 탄환 밀도 일관성 확보.

4. 탄막 및 게임 알고리즘 (Algorithm Design)
--------------------------------------------------------------------------------
- 수학적 패턴 및 셰이더 효과:
  * '악마의 심박', '성운의 이중주' 등 복잡한 삼각함수 탄막을 GPU 부하 없이 실시간 렌더링.
  * 셰이더 상수 버퍼(Constant Buffer)를 활용하여 탄환별 실시간 회전, 크기 조절, 색상 변조 구현.

- 엔딩 시퀀서 및 연출 엔진:
  * 보스 처치 시 지형지물이 파괴되는 듯한 '맵 파괴 폭발 시퀀스' 자동화 엔진 구현.
  * 화면 전체를 덮는 수백 개의 폭발 개체를 프레임 저하 없이 동시 처리.

5. 기술적 정수 (Technical Highlights)
--------------------------------------------------------------------------------
- 하드웨어 가속 전환 성과:
  * GDI+ 대비 동일 오브젝트 수 기준 렌더링 성능 약 500% 향상.
  * 고품질 투명 폭발 이펙트 동시 출력 개수 무제한 확장 가능.
- 가변 정밀 피격 판정(Adaptive Hitbox): 
  * 보스의 파츠별(본체, 날개) 독립 피격 판정 및 무적 상태 로직의 무결성 확보.
- 사용자 경험 혁신: 
  * 5초 자동 카운트다운 재시작 시스템 및 GPU 기반 실시간 FPS 모니터링 툴 내장.
- 엔진 안정성: 
  * DX11 장치 유실 및 복구, 리소스 재로딩 시나리오에 대처하는 견고한 초기화 로직 구축.
